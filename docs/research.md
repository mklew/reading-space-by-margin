# Readwise browser observations

Observed on 2026-10-22 through the signed-in Readwise Reader browser UI. This document describes product behavior without copying the user's library into the new application.

## Library

The left sidebar groups Home, Ghostreader, Library, content types, Tags, Feed, pinned views, Trash, Search, and Preferences. The Library has Inbox, Later, and Archive tabs. Rows show a thumbnail, title, summary, source, author, reading time, date, and reading progress. The selected row exposes quick actions. A right panel has Info, Notebook, and Ghostreader tabs. Sorting defaults to date moved.

## Reading

Opening an article changes the URL to a document route. The reading view has a contents panel, a central article, and the contextual right panel. The toolbar includes appearance, inbox removal, later, archive, and more actions. Previous and next document navigation sits beside the return-to-inbox control. The title area shows source, author, reading time, and Listen. Find-in-document has previous and next result controls.

## Appearance

The appearance popover exposes light, dark, and automatic themes, typeface, font size, line spacing, and reading width.

## Notebook

The notebook contains an editable document note with Save and Cancel controls, a highlights list, Export, and an Open link. An unannotated article shows an explicit empty state.

## Add menu

The Add menu offers URL, file upload, email, RSS feed, Twitter list, YouTube channel, integrations, browser extension, apps, and document discovery. These are observed menu entries. Their end-to-end behavior has not yet been tested.

## Feeds and mobile capture

The Manage feeds page has Subscribed and Suggested tabs, a search field, and Add feed. Its table separates name, description, document count, folders, and last updated. Add feed opens a name-or-URL input. Entering a public RSS URL offers an Add action. No subscription was created in the user's account during research.

The getting-started text links native Android and iOS apps for both saving and reading. Browser extensions are a separate capture channel. The user confirmed that collecting internet material, sharing from a phone, and subscribing to feeds are central to the requested product.

## Search

Search is a dedicated route with a library-wide query field, Clear search, a result count, and the contextual item panel. A query was entered through the UI. Search completion and ranking have not yet been verified.
