# The Margin handbook

A quieter place for everything you want to read. Margin collects articles, feeds and books in a personal library, with your notes alongside the words that mattered.

This handbook explains the product as it works today: how to use it, run your own installation, and understand the code behind it.

## Your library, your pace

Save a public URL or paste a note. Bring in a PDF or EPUB. Follow feeds separately from the reading list, then save the entries you want to keep. Use folders for decisions, tags for subjects, and saved views for questions you ask repeatedly.

Margin is an active, self-hosted MVP with one account per installation. It is an independent project inspired by Readwise Reader, with no affiliation to Readwise. [Known limits](guide/features.md#not-yet-supported) are part of the documentation, not hidden in a roadmap.
