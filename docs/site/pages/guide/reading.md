# Organize and read

Start with the default Triage workflow. Save an item to Inbox, move it to Later when you want to read it, then Archive it when you are finished. Archive keeps the document in your library.

## Choose a workflow

Change the workflow in Settings.

| Workflow | New captures | Primary locations |
| --- | --- | --- |
| Triage | Inbox | Inbox → Later → Archive |
| Shortlist | Later | Later → Shortlist → Archive |
| Classic | Later | Later → Archive |

Changing the mode changes the destination of future captures. It does not move existing documents. Previously populated Inbox or Shortlist locations remain accessible.

## Use tags and views for different jobs

Use a folder to describe the next reading decision. Use tags for topics such as `design` or `research`. A saved view is a live query over the library rather than a copied collection.

For example, `tag:research AND in:later AND minutes__lt:10` collects shorter research reads in Later. Pin a saved view to keep it in the navigation. See the [query reference](../reference/queries.md) for syntax.

## Keep notes alongside a passage

Open a document, select text and create a highlight. Add a note or tags to the highlight, or use a document note for thoughts about the whole piece. The global notebook helps revisit annotations without opening every document first.

Edits use revisions to detect conflicting changes. If another tab has changed the same record, reload its current values before retrying. The editor retains the draft for conflict recovery.

## Make the reader comfortable

Settings offers theme, typography, reading width and default side-panel preferences. Use Find in document for a passage and the listening control for system speech. Speech availability and voices depend on the browser.

## Keyboard shortcuts

| Key | Default action |
| --- | --- |
| `n` | Save a document |
| `/` | Search library |
| `j` / `k` | Next / previous document |
| `e` | Archive document |
| `l` | Move to Later |
| `b` | Open notebook |

Customize these in Settings. Leave a binding blank to disable it. Shortcuts pause while typing in editable controls, during text composition, and when Control, Command or Alt is held.
